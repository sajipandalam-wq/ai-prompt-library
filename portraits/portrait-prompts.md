# Portrait Prompts

All of these use the [sandwich face-lock](../techniques/face-lock-sandwich.md).

## 1. Cinematic studio portrait

```
Use the uploaded photo as the exact face reference; keep identical facial features.
Cinematic studio portrait of the man in a [dark brown blazer], seated on a wooden stool, moody Rembrandt lighting, deep charcoal backdrop, 85mm lens, shallow depth of field, 4:5.
The face must match the reference 100%. Photorealistic, natural skin texture.
```
